Master Motors — car workshop website

Open index.html in a modern browser, or serve this folder with a static web server.

Includes job cards, inspection notes, technicians, status tracking, itemised estimates,
customer and vehicle histories, invoices, configurable tax, payment recording,
print-to-PDF, editable service catalogue, reports and JSON backup/restore.

Records are stored in browser localStorage. This is a functional prototype, not a
production multi-user system. No cloud database, staff authentication, inventory,
online payment gateway, messaging or myTVS integration is included.

Service prices are explicitly labelled sample rates. Exact myTVS rates were not
available on the official pages checked. Update the catalogue using an authorised
rate card; existing job estimates keep their original rates.

Independent application. Not affiliated with myTVS.
